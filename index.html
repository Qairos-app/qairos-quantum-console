SECTION 02 // HOW IT WORKS

A sensor, then a switch

Qairos measures quantum capability with real cryptographic bounties, publishes it as one on-chain number, and lets every contract and holder react automatically.

1Canary

Twelve elliptic-curve keys from 16 to 256 bits carry bounties. The contract verifies any claimed key by itself.

2Oracle

Each broken armed key (128 bits and up) raises threatLevel() by one, from 0 to 5.

3Guard

Contracts that inherit QairosGuard lock sensitive functions when the level reaches their threshold.

4Ark

Holders who registered a post-quantum key beforehand recover funds with proof no attacker can forge.

5Markets

Prediction markets and insurance settle straight from the oracle. No votes, no disputes.

The Qairos Moment

The first time an armed canary key breaks. It is recorded on-chain as a timestamp, and every Qairos module reacts to it.

SECTION 07 // FAQ

Questions

Short answers. The app has the full detail.

Can Qairos stop a quantum computer?

No. Qairos detects the capability as soon as someone proves it on-chain, then triggers the protections you set up in advance: locked contracts, a recovery path and insurance.

What if an attacker never claims a bounty?

Then the canary stays silent. Qairos catches attackers who reveal capability for money. That is why the Ark and Guard should be set up early, not only when the alarm sounds.

Are my keys sent anywhere?

No. Keys are generated and used inside your browser. Only a 32-byte hash goes on-chain. The recovery kit is saved only when you choose to download it.

Why can training rungs be solved in a browser?

They are small on purpose (16 to 96 bits) to prove the mechanism end to end. They never move the threat level. Only armed rungs from 128 bits up do.

Can I use it on mainnet today?

Not yet. The contracts are tested and the app already builds correct L1 transactions. Mainnet follows the testnet phase and an independent audit.
